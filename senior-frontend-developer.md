## About the Role

We are looking for a **Senior Frontend Developer** to build and optimize modern, scalable, and user-friendly web applications.

The ideal candidate has strong expertise in React.js and modern frontend technologies, along with experience in chatbot interfaces, e-commerce integrations, and AI-powered applications. You will collaborate with cross-functional teams to deliver high-performance digital experiences in a fast-paced environment.

## Key Responsibilities

- Design, develop, and maintain high-performance, reusable UI components for React-based applications.
- Build interactive quiz experiences within chatbot interfaces and seamless e-commerce integrations.
- Collaborate with UI/UX designers to translate wireframes into responsive and accessible interfaces.
- Integrate frontend applications with Python/C# APIs and backend services.
- Optimize application performance, scalability, and responsiveness across devices.
- Lead code reviews, mentor junior developers, and promote coding best practices.
- Contribute to frontend architecture decisions, technical standards, and development guidelines.

## Requirements

### Frontend Development

- 5+ years of experience as a Frontend Developer or in an equivalent role.
- Bachelor's degree in Computer Science, Web Design, or a related field.
- Strong proficiency in React.js, including Hooks, Context API, and state management solutions.
- Advanced JavaScript/TypeScript skills and a solid understanding of modern ES6+ features.
- Experience with Micro-Frontend architecture.
- Proficiency in frontend build tools such as Webpack, Babel, and Vite.
- Solid understanding of RESTful APIs and experience working with MongoDB.

### Testing & Application Architecture

- Hands-on experience setting up frontend testing environments using Jest and React Testing Library.
- Experience applying Test-Driven Development (TDD) to React applications.
- Understanding of Server-Side Rendering (SSR), SEO optimization, and UI/UX principles.
- Experience building CMS platforms, page builders, editors, or file management systems.

### AI, Chatbots & Integrations

- Experience integrating LLM APIs, including OpenAI, Anthropic, or similar platforms.
- Understanding of LLM fine-tuning or other techniques to improve chatbot accuracy.
- Experience optimizing LLM application latency and performance.
- Familiarity with LangSmith for debugging and optimizing function-calling workflows.
- Experience with Firebase, Google Analytics, and A/B testing in chatbot environments.
- Familiarity with real-time communication protocols such as WebSocket and Server-Sent Events.

### Databases & Cloud Technologies

- Working knowledge of databases and data technologies, including MongoDB, PostgreSQL, MS SQL, Amazon Redshift, Redis, and Elasticsearch.
- Familiarity with cloud platforms such as AWS and GCP.
- Strong debugging skills, including the ability to investigate issues across frontend applications, backend services, and APIs.

## Nice to Have

- Basic Python or C# knowledge for effective collaboration with backend engineers.
- Experience with conversational UI, chatbot interfaces, or big data/reporting systems.
- Familiarity with WCAG accessibility standards.
- Experience with CI/CD pipelines and cloud deployments across AWS, GCP, or Azure.

## Soft Skills

- **Strong organizational skills:** Able to manage tasks effectively and maintain clean, testable code.
- **Clear communication:** Comfortable explaining technical concepts to technical and non-technical stakeholders.
- **Startup mindset:** Proactive, adaptable, and enthusiastic about emerging technologies.
- **Attention to detail:** Committed to optimizing workflows, code repositories, and technical documentation.
