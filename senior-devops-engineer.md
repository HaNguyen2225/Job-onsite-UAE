# 🚀 We're Hiring: DevOps Engineer

📍 **Location:** UAE  
💼 **Work Arrangement:** On-site  
🕒 **Employment Type:** Full-time

## About the Role

We are looking for a skilled **DevOps Engineer** to join our technology team in the UAE. You will help build, maintain, and optimize cloud infrastructure, deployment pipelines, and monitoring systems to ensure our applications remain reliable, scalable, and secure.

The ideal candidate has hands-on experience with cloud platforms, infrastructure automation, containerization, and CI/CD, and enjoys collaborating with development and operations teams in a fast-paced environment.

## Key Responsibilities

- Design, implement, and maintain reliable, scalable, and secure infrastructure.
- Build and optimize CI/CD pipelines to automate application build, testing, and deployment.
- Manage cloud infrastructure and services, preferably on AWS.
- Implement and maintain infrastructure automation using Infrastructure as Code (IaC) tools.
- Deploy and manage containerized applications using Docker and Kubernetes.
- Monitor system performance, availability, and resource utilization.
- Troubleshoot infrastructure, deployment, networking, and application issues.
- Implement security best practices, access controls, backup strategies, and disaster recovery procedures.
- Collaborate with Backend, Frontend, QA, and other engineering teams to improve release quality.
- Maintain technical documentation and continuously improve DevOps processes.

## Requirements

- Proven experience as a DevOps Engineer, Cloud Engineer, Site Reliability Engineer, or in a similar role.
- Have 5 years experience with DevOps Engineer
- Strong knowledge of cloud infrastructure, particularly AWS.
- Hands-on experience with Docker and Kubernetes.
- Experience designing and maintaining CI/CD pipelines using tools such as Jenkins, GitLab CI/CD, or GitHub Actions.
- Familiarity with Infrastructure as Code tools such as Terraform or Ansible.
- Good understanding of Linux administration, networking, and system troubleshooting.
- Experience with monitoring and logging tools such as Prometheus, Grafana, or the ELK Stack.
- Knowledge of scripting languages such as Bash or Python.
- Understanding of cloud security, system reliability, and performance optimization.
- Strong analytical, troubleshooting, and problem-solving skills.
- Ability to collaborate effectively with cross-functional engineering teams.

## Nice to Have

- Experience with multi-cloud environments, including AWS, Azure, or GCP.
- Knowledge of microservices architecture.
- Experience with GitOps tools such as Argo CD or Flux.
- Familiarity with security automation and DevSecOps practices.
- Experience optimizing cloud infrastructure costs and resource utilization.

## Benefits

- Competitive salary based on experience and qualifications.
- Opportunity to work in an international technology environment.
- Exposure to modern cloud infrastructure and automation technologies.
- Opportunities for professional development and continuous learning.
